# را، رو، ـو | The object marker
A definite object — this book, the car, my keys — takes **رو** (written را, said ro or o).
- **کتاب رو خوندم** — I read the book.
- **کلیدامو پیدا نمی‌کنم** — I can't find my keys.

## After a consonant it shrinks to ـو
**اینو** (this, as an object), **اونو**, **منو** (me), **ماشینو**. Both spellings are right: این رو and اینو.

## No marker for "a" or "some"
An indefinite object takes nothing: **یه کتاب خریدم** (I bought a book). Add رو and it becomes "the book": **کتابو خریدم**.
