# گفتاری و نوشتاری | Spoken vs written
Signs, books and news use written Persian; people speak another register. This vault teaches the spoken one. The commonest shifts:
| written | spoken |
|---|---|
| می‌روم | می‌رم |
| می‌آیم | میام |
| می‌خواهم | می‌خوام |
| می‌گویم | می‌گم |
| است | ـه / ـست |
| را | رو / ـو |
| خانه | خونه |
| نان | نون |
| آن | اون |
| یک | یه (before a noun) |
| برای | واسه (casual) |

## The ân → un shift
Many words with ân say un: **خونه، نون، اون، زبون، خیابون، آسون، ارزون**. Not every ân does: **ایران** stays ایران.

## Endings
3rd plural ـند → **ـن** (می‌رن). 2nd plural ـید → **ـین** (می‌رین), with ـید still heard in polite speech.
