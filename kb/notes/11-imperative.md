# امری | Telling someone to do it
To تو: **بـ + present stem**, no ending. To شما: add ـین.
| | تو | شما |
|---|---|---|
| رفتن | برو | برین |
| اومدن | بیا | بیاین |
| گفتن | بگو | بگین |
| دادن | بده | بدین |
| نشستن | بشین | بشینین |
| کار کردن | کار کن | کار کنین |

## Don't
نـ instead of بـ: **نرو**, **نگو**, **نیا**, **نترس**.

## Softening it
**لطفا** in front, or the polite **بفرمایین** (please, go ahead) on its own.
